Os cinco padrões

01 · Circuit Breaker

Falha rápida

Monitora falhas consecutivas por serviço downstream. Quando atinge o threshold, abre o circuit e rejeita chamadas imediatamente — sem esperar timeout.

02 · Bulkhead

Isolamento de recursos

Cada agente tem seu próprio pool de slots via CapacityLimiter. Um agente lento não consome os recursos dos outros.

03 · Retry + Backoff

Recuperação inteligente

Exponential backoff com full jitter dessincroniza clientes. Integrado com circuit breaker — não retenta se o circuit está OPEN.

04 · Cascading Timeout

Budget propagado

O timeout restante da request viaja como header X-Timeout-Budget. Cada agente na cadeia respeita o budget do chamador.

05 · Backpressure

Limite de fila

A recovery queue tem tamanho máximo controlado via Lua atômico. Overflow vai direto para DLQ — evita acúmulo ilimitado no Redis.

Circuit Breaker — implementação

class CircuitBreaker:
    async def call(self, fn, *args, **kwargs):
        async with self._lock:
            if self._state == CircuitState.OPEN:
                if self._should_attempt_reset():
                    self._transition_to(CircuitState.HALF_OPEN)
                else:
                    raise CircuitOpenError()  # falha imediata

        try:
            result = await fn(*args, **kwargs)
            await self._on_success()
            return result
        except self.cfg.expected_exception as exc:
            await self._on_failure(exc)
            raise

    def _calculate_delay(attempt, cfg):
        delay = min(cfg.base_delay * (cfg.exponential_base ** attempt), cfg.max_delay)
        return random.uniform(0, delay)  # full jitter
Integração circuit breaker × retry: falhas contadas no retry alimentam o circuit breaker automaticamente. Quando o circuit abre, o retry para imediatamente ao receber CircuitOpenError — sem gastar tentativas.

script = """
local size = redis.call('LLEN', KEYS[1])
if size >= tonumber(ARGV[1]) then
    return 0  -- fila cheia → vai para DLQ
end
redis.call('RPUSH', KEYS[1], ARGV[2])
return 1  -- enfileirado
"""

result = await redis.eval(script, 1,
