Sampling strategies

Ambiente Sampler Ratio Comportamento
dev TraceIdRatioBased 1.0 captura 100% — visibilidade total
staging ParentBased(Ratio) 0.5 respeita decisão do pai A2A
prod baixo volume ParentBased(Ratio) 0.1 10% · pai decide para a cadeia
prod alto volume ErrorAwareSampler 0.01 1% normal · 100% em erros

ParentBased é a chave para multi-agent: se o orquestrador samplea o trace, todos os agentes filhos na cadeia seguem a mesma decisão. O trace_id é sempre o mesmo — só a decisão de exportar ou não muda.

@traced_node — decorator para nós LangGraph

def traced_node(node_name, attributes=None):
    def decorator(func):
        @wraps(func)
        async def wrapper(state, config, *args, **kwargs):
            thread_id = config["configurable"]["thread_id"]

            with tracer.start_as_current_span(
                f"langgraph.node.{node_name}",
                kind=SpanKind.INTERNAL
            ) as span:
                span.set_attribute("langgraph.node", node_name)
                span.set_attribute("langgraph.thread_id", thread_id)
                try:
                    result = await func(state, config, *args, **kwargs)
                    span.set_status(Status(StatusCode.OK))
                    return result
                except Exception as exc:
                    span.record_exception(exc)
                    span.set_status(Status(StatusCode.ERROR))
                    raise
        return wrapper
    return decorator

# Uso — compõe com outros decorators
