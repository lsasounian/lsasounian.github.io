Vetores de ameaça

alto risco

Tool results maliciosos

API externa retorna conteúdo com instruções de injection. O LLM não distingue dado de instrução se não houver separação estrutural.

alto risco

Estado A2A comprometido

Agente comprometido injeta payload no estado compartilhado. Outros agentes na cadeia processam como dado legítimo.

médio risco

Documentos ingeridos

PDF, HTML ou página web com instruções escondidas. Vetores comuns: comentários HTML, texto branco sobre fundo branco, zero-width characters.

médio risco

Memória / histórico

Conteúdo malicioso salvo no checkpoint LangGraph contamina sessões futuras quando o estado é retomado.

Defesa em 4 camadas — prompt injection

1
Separação estrutural no prompt
system prompt = instruções confiáveis · dados externos = user role
build_safe_prompt(system_instructions, tool_results, user_message)
2
Sanitização de tool results
regex patterns · sinaliza suspeitos · não remove — decide
sanitize_tool_results(results) → {content, _suspicious, _patterns}
3
Validação de estado A2A
Pydantic com extra="forbid" · rejeita campos desconhecidos
validate_incoming_state(raw_state, source_agent) → TrustedAgentState
4
Validação de output pós-LLM
última linha · bloqueia antes de agir · loga para SIEM
validate_llm_output(output, node_name) → {is_safe, reason}

JWT — claims obrigatórios

iss "auth-service" quem emitiu
sub "booking-agent" identidade do agente
aud "agent-platform" validado pelo receptor
exp now + 900 TTL 15 minutos
jti uuid4() ID único para revogação
scope "search:invoke" subset do autorizado

TokenManager — cache e renovação

class TokenManager:
    async def get_token(self) -> str:
        if self._is_valid():
            return self._token  # cache hit

        async with self._lock:  # evita múltiplas renovações simultâneas
            if self._is_valid():
                return self._token  # double-check após lock
            await self._fetch_token()
            return self._token

    def _is_valid(self) -> bool:
        # Considera inválido 60s antes de expirar (refresh_margin)
        return time.time() < (self._expires_at - self._refresh_margin)

# Uso no a2a_client.py — uma instância por agente
token_manager = TokenManager(
    auth_url="http://auth-service",
    client_id="booking-agent",
    client_secret=os.getenv("CLIENT_SECRET"),
    scope="search:invoke",
)

require_scope — FastAPI dependency

# Valida JWT localmente — sem roundtrip para o Auth Service
def require_scope(scope: str):
    async def _dependency(credentials = security) -> dict:
        return validate_token(credentials.credentials,
                              required_scope=scope)
    return _dependency

# Uso no endpoint
@app.post("/search/invoke")
async def search_invoke(
    body: SearchRequest,
    claims: dict = Depends(require_scope("search:invoke")),
):
    caller = claims["sub"]  # "booking-agent" — para auditoria
    return await run_search(body)
