Terraform — task definitions

# Agent task
container_definitions = jsonencode([
  {
    name    = "agent"
    image   = "${aws_ecr_repository.app.repository_url}:latest"
    command = ["python", "app.py"]
    environment = [
      { name = "REDIS_URL",      value = var.redis_url },
      { name = "SERVICE_NAME",   value = "booking-agent" },
      { name = "OTLP_ENDPOINT", value = "http://localhost:4317" },
    ]
    stopTimeout = 120  # aguarda tasks ativas terminarem
  },
  {
    name  = "xray-daemon"
    image = "amazon/aws-xray-daemon:latest"
    portMappings = [
      { containerPort = 4317, protocol = "tcp" },  # OTLP
      { containerPort = 2000, protocol = "udp" },  # X-Ray nativo
    ]
  }
])

# Recovery Worker task — mesma imagem, comando diferente
container_definitions = jsonencode([{
  name    = "recovery-worker"
  image   = "${aws_ecr_repository.app.repository_url}:latest"
  command = ["python", "recovery_worker.py"]
  environment = [
    { name = "REDIS_URL",               value = var.redis_url },
    { name = "RECOVERY_MAX_ATTEMPTS",   value = "3" },
    { name = "RECOVERY_QUEUE_MAX_SIZE", value = "100" },
  ]
}])

Dockerfile — entrypoint flexível

# Sem CMD fixo — definido no ECS task definition via command[]
# Permite reutilizar a mesma imagem para agent e recovery-worker
FROM python:3.12-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt --no-cache-dir

COPY . .

# Sem CMD aqui — ECS passa ["python", "app.py"]
# ou ["python", "recovery_worker.py"] via task definition

Essa abordagem evita manter dois Dockerfiles sincronizados. O código base é o mesmo — só o entrypoint muda por environment.

Por que o Recovery Worker não fala com o Agent Task

É um equívoco comum imaginar que o worker precisaria "avisar" o agente. Ele não se comunica com nenhum ECS task — apenas com o Redis.

# O estado vive no Redis, não no processo
# Quando o ECS task morre:
#   - Processo: perdido
#   - Checkpoint (Redis): intacto
#   - Heartbeat (Redis): expira em 30s
#
# Recovery Worker detecta: heartbeat expirou, checkpoint existe
# Recovery Worker age: ainvoke(None, thread_id)
# LangGraph age: lê checkpoint do Redis → continua
#
# Nenhuma comunicação inter-processo necessária.
